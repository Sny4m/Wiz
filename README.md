# **WIZ**

### Wise Interactive Companion

> **Your local AI companion for your laptop.**

Fast. Private. Voice-first. Built to actually work with you.

> 🚧 **WIZ is currently under development.**

---

## ✨ What is WIZ?

WIZ is a local AI assistant designed to live on your laptop.

Talk to it naturally, ask it to do things, and let it work with your system.

**Local when possible. Useful when needed.**

---

## 🎙️ Voice First

WIZ is built to feel natural to talk to.

- 🎤 Speech-to-text
- 🔊 Text-to-speech
- 🗣️ Voice interaction
- 📊 Animated voice feedback

---

## 🖥️ Laptop Companion

WIZ is being built to work with your computer, not just chat.

- 📁 Files
- 💻 Terminal
- 🖱️ Computer control
- 🧠 Memory
- 🛠️ Tools

---

## ⚡ Why I Built WIZ

I wanted an AI assistant that actually felt like it belonged on my laptop.

Something I could talk to, use, build with, and keep improving.

So I built WIZ.

🐿️ **And this is only the beginning.**
